# Rebuilt Gentoo Fetch Branding

This directory contains the Rebuilt Gentoo identity used by system-information/fetch applications.

## Identity

- Name: Rebuilt Gentoo
- ID: `rebuilt-gentoo`
- Release model: Rolling
- Base: Gentoo Linux
- Package manager: Portage / emerge

The ASCII logo is stored in `rebuilt-gentoo-fetch.txt` and the machine-readable branding is in `rebuilt-gentoo.conf`.

Fetch applications can use the ASCII logo and these values when adding Rebuilt Gentoo as a custom OS identity.
